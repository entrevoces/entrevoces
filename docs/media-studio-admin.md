# Public media studio

`/admin/` is deliberately public: anyone with its URL can read draft scripts, play included legacy demo recordings and request generated voice clips. It is separate from the learner library, which still includes only explicitly published and approved media. Do not put confidential scripts or credentials in the authoring catalog. The Modal endpoint accepts only the bounded text segments in the deployed catalog, applies a best-effort single-container rate limit and never accepts arbitrary text. Public use can incur Modal compute charges.

Select a script, choose English or Spanish, and press **Generate voice**, or use **Generate voices for all scripts**. Meta's `facebook/mms-tts-eng` and `facebook/mms-tts-spa` run on CPU-only Modal workers. A completed reading can be played or downloaded as a WAV. The model produces one synthetic voice per selected language; it does not sing or provide distinct actors. Some stage directions and speaker headings are omitted from the spoken draft. Mixed-language scripts require careful review: the selected voice reads the entire script, and may mispronounce the other language. Review names, numbers, negation and meaning by listening before using or approving a recording. The model weights are CC-BY-NC 4.0.

Completed segments are stored in IndexedDB in the current browser. Pause stops after the current segment; resuming reuses completed segments. Closing the page stops the queue, but saved segments remain available on the same browser and device. Browser storage can be cleared or evicted, so download any draft you want to keep. Scripts and audio drafts do not become library content through this screen. Use the signoff, rights and publishing steps in [VIDEO_STUDIO.md](VIDEO_STUDIO.md) for a finished asset.

The Pages build emits `admin-data/catalog.json` containing a narrow, deliberately public projection of draft titles and scripts. The existing Modal service receives a copy at deployment, so the two deployments must use matching script segment revisions; a mismatch returns an actionable error. Deploy Modal after `npm run build`, then push Pages. No access codes or provider credentials are included in the Pages bundle.
