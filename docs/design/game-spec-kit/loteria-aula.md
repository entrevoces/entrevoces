# Lotería de Aula — classroom caller (exists, to spec)
Fantasy: fiesta night; you are the caller with the big cards.
Loop: call a card aloud → boards hunt → mark with a frijol → line wins a sentido round.
Controls: one Call button / Space; taps to mark. Designed for a projector.
Fail: wrong tap stings kindly; a line without interpretation does not win.
Juice: papel-picado sway, caller cries, bean markers, room-win confetti.
Interpretation: Stage 1 listening all game; winning requires Stage 8 sentence carry.
