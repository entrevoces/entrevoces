# Neon Bastion — platform shooter (exists, to spec)
Fantasy: last defender of a dusk bastion; glitch-drones carry stolen words.
Loop: run/jump platforms → shoot the drone carrying the true equivalent → wave clears.
Controls: arrows/AD + W jump + Space/J or tap.
Fail: neighbour drone = shield crack; 3 cracks end the night.
Juice: muzzle flash, bursts, screen shake on shield loss, parallax mesas.
Progression: waves speed up; every 3rd wave is a sentence wave (word in context).
Interpretation: Stage 6 under fire; sentence waves Stage 5.
