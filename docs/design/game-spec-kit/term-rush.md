# Term Rush — Catch the Rain
Fantasy: a street interpreter with a big basket catching falling word-drops in a neon storm.
Loop: move catcher → drops fall with words → catch the true one in the basket → combo grows.
Controls: mouse/finger follows; arrows/A,D.
Fail: wrong catch splashes, gold drop hitting ground pops; 3 splashes end the run.
Juice: splashes, combo flames, basket bounce, rain streaks, thunder on meaning waves.
Progression: rain speeds up; every 4th drop is a meaning drop (definition falls, catch its word).
Visual: night market street, awnings, glowing drops. Prompt is weather, not a worksheet.
Interpretation: Stage 6 speed; meaning waves Stage 3.
Session ~3 min runs, daily best. Comfort: rain starts slower, first splash forgiven.
