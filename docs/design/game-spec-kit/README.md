# game-spec-kit — how games are regenerated here

Rule zero: if the spec's core loop reads like a quiz, the game does not ship.
Every game is specified in TEMPLATE.md format, built scene-first (canvas or
constructed set), text lives on in-world objects (blocks, drones, melons,
cards), and the shared packages/game-kit supplies juice (particles, shake,
floating text, synth SFX) so no game ships silent or static. DOM is for
menus, reports and the Hub — never for the moment of play where a canvas
can carry it. Calibration source: app-store games a person opens for fun;
the learning is the physics, not the worksheet.
