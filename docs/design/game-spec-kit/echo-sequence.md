# Echo Sequence — Firefly Path
Fantasy: a lantern-bearer crossing a night pond on stepping stones lit by a firefly.
Loop: firefly lights a path (hear it) → tap stones in order → bearer walks your path → path grows.
Controls: tap/click stones; keyboard 1-9.
Fail: wrong stone = bearer stumbles, petal-heart dims; 3 stumbles end the walk, kindly.
Juice: ripples, firefly trail, lantern glow, stone chimes rising in pitch.
Progression: path 1→10 stones, pace quickens, every 3rd walk is reverse (heard in the other tongue, stones show home words only).
Visual: dusk pond, lily pads, glowing stones, lantern-bearer. Text only on stones.
Interpretation: Stages 6-7 ordered memory + spoken production; reverse = listening.
Session ~6 min; tomorrow-hook: longest-path best + streak.
Comfort: no hearts lost on first walk of the day; replay free.
