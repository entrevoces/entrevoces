# Melon Reef — underwater harvest (exists, to spec)
Fantasy: pilot Meloncita, a watermelon submarine, through a listening reef.
Loop: hear a word → swim into its English melon → oxygen refills; wrong melon = jelly sting.
Controls: pointer follows; WASD/arrows.
Fail: oxygen empties = surface (never a "game over" scolding).
Juice: bubbles, god rays, blush, happy loop spins.
Progression: every 3rd dive is a whole-sentence phrase dive. Interpretation: Stage 1 listening, Stage 5 phrases, reverse direction.
