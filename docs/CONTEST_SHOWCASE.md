# Competition-ready demo plan (honest engineering scope)

Entre Voces should look like a **human, delightful, adult entertainment library**, not a set of arcade minigames. The core interaction is listening and recognizing when an interpreter alters meaning. The spectacle comes from original memorable stories, recurring characters, warmth, music, and immediately consequential subtle errors.

## Three-minute live demo script — design target, not claims of deployed media

| Clock | Show | What judges should understand |
|---|---|---|
| 0:00–0:25 | Open `Biblioteca Viva` home on mobile; a prominent playable Suno song and library shelves | Training content is consumable entertainment; live GPUs are unnecessary for replay |
| 0:25–1:05 | Start an approved, prerecorded Spanish–English dialogue; hit/voice “Alto” when uncertainty or dosage is mistranslated | Actual interpreting skill is preserving meaning; listening detection, not arcade reflexes |
| 1:05–1:35 | Reveal the exact English and Spanish lines; show subtle negation, uncertainty, dosage and timing distinctions, with source IDs | Knowledge is traceable to 865 real terms and richer conceptual relationships |
| 1:35–2:00 | Telenovela *La última palabra* episode preview (narration draft unless actors recorded); branching audio mystery | Humor, story continuity and choice create emotional memory |
| 2:00–2:35 | Desktop creation: choose an underlearned concept, produce a frozen brief, show live Meta Wonder/Spark workflow and one real API artifact | An engine that invents new high-quality media based on a structured educational need |
| 2:35–3:00 | GitHub Actions passing offline suite + actual Meta inference results + protected human review gates | Real models create drafts; independent gatekeeping prevents AI errors from becoming “truth” |

Do not say “fully voice driven” until an actual audio-bound conversation has been produced and validated. Web SpeechRecognition is opt-in and may use third-party network services. If media is not produced, demonstrate the complete script with explicitly labeled device-voice draft narration.

## Core judged criteria

- **Innovation:** a deterministic data-driven suggestion engine proposes *genres and media assets*, not just more questions.
- **Real-world learning utility:** separate recognizing an error from oral interpretation proficiency; do not record unverified stage-8 performance.
- **Craft:** actual complete scripts, recurring cast, sound queues, accessible listening, intentional adult cultural context without stereotypes.
- **Scalability:** expensive generation once; serve cheap static assets to many listeners through GitHub Pages.
- **Safety:** every consequential clinical/legal statement maintains source traceability, review state, and correct negation/quantities/uncertainty.
- **Production reproducibility:** measured provider ID/usage, GitHub artifact, source hash, model benchmark and rollback.

## Hard stop before contest demonstration

A prototype is not ready to represent professional competency until: real audio aligned; at least one full authentic bilingual conversation; professional reviewer signoff; actual Meta API paid-workflow result; correct content permissions; physical iPhone accessibility test; completed GitHub Pages verification. If any is missing, explicitly call the demo an engineering preview and use the static scripts without inflating its completeness.

## Prioritized production sprint

1. Record and review one fully bilingual *catch the change* interaction with 3 recurring voices. Preserve all stems; establish actual millisecond error windows; test with 5 adults.
2. Record one *La última palabra* complete episode with warm dramatic sound and a meaningful cliffhanger. Use actual dialogue, not a 150-word teaser.
3. Produce a second Suno musical mnemonic from authored lyrics; verify share link and rights, keep it featured as a **song** not a worksheet.
4. Complete narrative branching with 2+ voiced endings, captions and stop/resume.
5. Run Meta paid workflows and publish reviewer-approved, static media. Export an assessment report without treating voice recognition accuracy as a fidelity score.
