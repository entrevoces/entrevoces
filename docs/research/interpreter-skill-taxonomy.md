# Interpreter Skill Taxonomy — the research spine (every skill trained, none repeated)

Interpreting is not "knowing two languages." Training research decomposes it
into separately trainable — and separately failable — skills. ENTRE VOCES
assigns each skill a *home game* with a *different interface*, so the portfolio
feels like three games, not three quizzes. The engine tracks all of them; no
game double-counts another game's proof.

## The skills (and where each lives)

|---|---|---|---|---|

## Note-taking, taken seriously (Rozan's seven principles, playable)

Jean-François Rozan (1956) — still the backbone of consecutive training:
(1) note *ideas*, not words; (2) abbreviation rules; (3) **links** are the
most important symbols (therefore, but, because, if); (4) **negation** must be
unmissable; (5) emphasis/underlining; (6) **verticality** — stack idea units
top-to-bottom with offsets so structure is visible; (7) shift — carry the
subject's position so pronouns never orphan. Night Shift teaches these as
*tools you hold*: a symbol palette (→ therefore · ≠ not · ↑ increase ·
? uncertain · ! must/obligation · § condition · " " quote), vertical jot
lines, and a Phase-1/Phase-2 split faithful to Gile — first you listen+note
(source plays, notebook open), then the source *leaves* and you reformulate
from notes alone. Note quality is scored (idea units captured, links/negation
present) and stored as evidence — bad notes are diagnosed, not just wrong answers.

## Consecutive's two phases (Gile) → Night Shift's two screens

Phase 1: Listening + Memory + Note-taking + Coordination. Phase 2: Remembering
+ Note-reading + Production. Most classroom apps collapse these into one box.
Night Shift refuses: the Interpret screen hides the source text by default
(reveal costs a Clarification Token), so memory and notes do real work — and
the effort bars (Listening/Memory/Production) show *which* capacity overflowed
when fidelity drops.

## Why the games never repeat

Same engine, disjoint verbs: **BUILD** (Atelier — spatial, constructive,
untimed mastery), **ENDURE** (Night Shift — temporal, auditory, stamina and
hearts), **DECIDE** (Bench Call — deliberative, textual, stamp-and-defend).
A concept (e.g., `waiver`) appears in all three *as different work*: craft its
rendering in the Atelier, survive it in a judge's long turn on Night Shift,
then sight-translate its written form and defend impartiality at the Bench.
The learner state is one career; the play never is.

## Oregon grounding

OJD requires complete/accurate verbatim rendering across sight, consecutive,
and simultaneous modes; OHA's 60-hour foundation (terminology/anatomy/modes +
8h ethics) defines the medical spine. Simultaneous is represented in v1 as
Pressure Timer + shadowing-style rapid retrieval (honestly labeled — full
simultaneous booth simulation is Tier 3), never faked.
