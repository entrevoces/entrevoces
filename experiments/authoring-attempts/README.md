# Superseded image-authoring attempts

The initial Meta Muse Image attempt returned HTTP 402 `billing_not_configured`. A user-requested Modal open-weight alternative then built its dependency image but was refused GPU execution because the account has no payment method. No art was produced by either route. The user subsequently explicitly requested ChatGPT-authored simple vector images, which are the actual shipped assets in `assets/game-vectors/`.

These files preserve the failed experiment; they are not part of player deployment and must not be described as successful media generation. Do not rerun without a new authoring need and appropriate account access. Never claim these outputs came from Meta.
