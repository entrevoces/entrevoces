# Learning validity adversary

Reconstruct the claimed learning outcome independently. Check whether success actually requires it, shortcuts earn false mastery, assisted/feedback-led completion is counted as independent success, or source-limited training implies broader proficiency. Trace every assessed response to the correct concept, stage, evidence and source boundary. Distinguish recognizing a supplied flag from diagnosing a real situation.

Required handoff: learning validity adversarial report.

Follow agents/common.md and the task-specific structured contract. List source evidence, decisions, residual risks and exactly which checks were performed. A passing schema is necessary but not evidence of domain depth, visual quality or fun.
